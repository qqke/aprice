# APrice 产品易用度与 UI 审计

日期：2026-07-20

## 审计范围

- 用户目标：未登录用户理解产品价值，并尝试通过搜索或扫码完成一次比价。
- 覆盖页面：首页、搜索错误态、扫码页、个人页、登录页、商品不存在/加载失败态。
- 覆盖视口：桌面 1272×621；移动端 390×844。
- 结论仅基于本次本地构建和截图。搜索、商品与验证码依赖在本地环境中请求失败，因此正常数据态、真实相机权限、完整登录流程和读屏体验未验证。

## 总体结论

视觉完成度高于流程完成度。首屏价值主张清楚、扫码入口醒目、移动端视觉有辨识度；但一旦进入搜索失败、未登录或商品缺失状态，页面会同时展开大量空模块、内部错误文案和不可用操作，用户很难判断下一步。

建议优先处理状态收敛与流程短路，而不是继续增加视觉装饰。

## 流程步骤

1. 首页进入 — 健康度：良好
   - 优点：一句话讲清“在店扫码比价”，扫码是视觉第一入口；桌面和移动端均无横向溢出。
   - 风险：桌面端“登录”和“未登录”重复表达；移动端搜索框没有可见提交按钮，且无可读名称，键盘回车虽可能可用但发现成本高。

2. 搜索与结果反馈 — 健康度：较差
   - 搜索失败后直接暴露 `Failed to fetch`，没有明确重试按钮。
   - 即使没有选中商品，仍展开“附近比价”、地图占位和三个功能入口，错误信息被大量空状态稀释。

3. 扫码与手动输入 — 健康度：一般
   - 优点：相机与手动输入双路径明确，主要按钮尺寸充足。
   - 风险：“页面加载后会自动启动”与“启动相机扫描”同时出现；“正在准备相机”在未授权/非 HTTPS 时容易长期悬置。
   - 移动端底部固定导航覆盖手动输入区域，首次视口内主任务被切断。
   - 标题层级为 H1 → H3 → H2，不利于读屏用户理解结构。

4. 未登录个人页 — 健康度：较差
   - 登录价值有说明，也保留了回跳承诺。
   - 但未登录时仍呈现积分、账号安全、收藏、价格记录、最近浏览等大量不可用模块；`offline` 与中文混排，像系统故障而非登录状态。

5. 登录页 — 健康度：一般
   - 登录、注册、找回密码集中在一个入口，信息架构合理。
   - 本次验证码加载失败直接阻断主任务，页面缺少面向用户的恢复路径。
   - 验证码、`guest` 等语言与中文界面不一致；“登录”“未登录”“账号状态”在同屏重复。
   - 本地带 base path 构建中，“返回首页继续搜索”指向 `/`，存在离开应用路径的风险。

6. 商品缺失/加载失败 — 健康度：差
   - 页面先声明“商品不存在”，却继续展示价格流、附近门店、价格洞察、记录价格和近期变化，页面高度约 2852px。
   - 用户仍能看到收藏、记录价格、位置排序等操作，状态与操作互相矛盾。
   - 门店错误再次暴露 `Failed to fetch`。

7. 移动端首页 — 健康度：良好
   - 视觉焦点明确，扫码按钮大且易触达，底部三项导航符合移动端使用习惯。
   - 搜索缺少显式提交动作；固定导航与长页面内容之间需要更安全的底部留白。

## 优先修改建议

### P0：先让失败态可恢复

1. 将所有 `Failed to fetch`、`offline`、`guest` 替换为统一中文状态，并给出“重试”或“返回搜索/扫码”的单一主操作。
2. 商品不存在或商品请求失败时立即短路，只保留商品标识、重新搜索、重新扫码；不要渲染价格流、地图、洞察和记录表单。
3. 验证码失败时明确说明原因和恢复动作；验证码不可用时不要让用户填完表单后才发现无法登录。

### P1：缩短核心任务

4. 搜索未选中商品前隐藏“附近比价”和地图，仅保留一个紧凑占位；选中商品后再展开。
5. 移动端搜索框增加可见的 44px 搜索按钮和稳定的可访问名称。
6. 扫码页统一状态：准备中、请求权限、扫描中、识别失败、非 HTTPS。自动启动成功时隐藏“启动”按钮；未启动时不要显示“正在准备”。
7. 移动端扫码页减少相机区高度，保证“手动输入 + 查找商品”在一次短滚动内完整出现；为固定底栏增加足够底部安全区。
8. 未登录个人页只显示三项核心收益和一个“登录后继续”按钮，其余模块登录后再渲染。

### P2：降低视觉与文案噪声

9. 顶栏只保留一个账户入口；“登录”和“未登录”二选一。
10. 减少白底玻璃卡片、阴影和套卡层级；一屏最多保留一个主容器层级。
11. 提高浅灰辅助文字对比度；统一中文产品术语和状态文案。
12. 修正扫码页标题层级，并实测键盘焦点、读屏名称、200% 缩放和真实相机权限流程。

## 建议验收指标

- 首页到首次价格结果的中位耗时。
- 搜索提交成功率、失败后重试成功率。
- 相机授权 → 首次识别成功率。
- 商品缺失页返回搜索/扫码的点击率。
- 登录页验证码失败率与登录完成率。
- 移动端扫码页在不误触底栏情况下完成手动查询的比例。
